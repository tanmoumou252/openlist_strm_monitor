# 部署指南

本文档介绍如何在 Windows 环境下部署和运行 openlist_strm_bridge。

---

## 系统要求

- **操作系统**: Windows 10/11 或 Windows Server 2016+
- **Python**: 3.11+（项目自带嵌入式 Python 3.14）
- **磁盘空间**: 至少 500MB（含数据库和日志）
- **网络**: 可访问 OpenList 服务（局域网或公网）

---

## 快速开始

### 1. 下载项目

```
# 直接下载 ZIP
# 从 GitHub Releases 下载最新版本
```

### 2. 安装依赖

项目自带嵌入式 Python 环境，无需手动安装依赖。

如需使用系统 Python：

```powershell
# 使用嵌入式 Python（推荐）
.\src\python_embed\python.exe -m pip install -r requirements.txt

# 或使用系统 Python
python -m pip install -r requirements.txt
```

**依赖列表**（requirements.txt）：
- `watchdog>=4.0.0` - 文件系统监控
- `requests>=2.31.0` - HTTP 客户端
- `lxml>=5.0.0` - XML 解析（WebDAV）
- `tomli>=2.0.1` - TOML 配置解析（Python < 3.11）
- `pyotp>=2.9.0` - TOTP 2FA 支持

### 3. 配置文件

复制示例配置：

```powershell
Copy-Item config.toml.example config.toml
```

编辑 `config.toml`：

```toml
[local]
# SQLite 数据库文件路径（相对路径基于 config.toml 所在目录）
db_file = "./bridge.db"

[webui]
# WebUI 管理面板配置
enabled = true
port = 8579
bind = "0.0.0.0"  # 0.0.0.0 = 局域网可访问，127.0.0.1 = 仅本机
```

**重要**：OpenList 连接配置、路径配置等已迁移至 WebUI 管理面板，首次启动后通过 WebUI 配置。

### 4. 启动服务

```powershell
# 方式一：使用批处理脚本（推荐）
.\嵌入式启动.bat

# 方式二：直接运行
python src/webui/server.py
```

启动后访问 `http://127.0.0.1:8579` 即可使用 WebUI 管理面板。

### 5. 访问 WebUI

启动后访问：`http://127.0.0.1:8579`

首次启动需配置：
1. **OpenList 配置** → 填写 WebDAV 地址、用户名、密码、TOTP 密钥（如有）
2. **路径配置** → 设置 B 区（媒体库）、C 区（幽灵收容）路径
3. **TMDB 配置**（可选）→ 填写 API Key 以启用待看列表功能

## 首次配置流程

### Step 1: 配置 OpenList 连接

访问 WebUI → **配置** → **OpenList 配置**：

- **WebDAV 地址**: `http://your-openlist:5244`
- **用户名**: OpenList 管理员用户名
- **密码**: OpenList 管理员密码
- **TOTP 密钥**: 如启用 2FA，填写密钥（可选）

点击 **测试连接** 验证配置。

### Step 2: 配置路径

访问 WebUI → **配置** → **路径配置**：

- **B 区根目录**: 媒体库消费区路径（如 `D:\MediaLibrary`）
- **C 区根目录**: 幽灵收容区路径（如 `D:\GhostFiles`）
- **STRM 引擎路径**: OpenList STRM 引擎挂载路径（如 `/strm`）

### Step 3: 配置行为（可选）

访问 WebUI → **配置** → **行为配置**：

- **启动时同步**: 是否在启动时执行全量同步
- **幽灵保护时间**: 文件删除后保留恢复窗口的时间（秒）
- **动作模式**: `MOVE`（移动到回收站）或 `DELETE`（直接删除，危险）

### Step 4: 配置 TMDB（可选）

访问 WebUI → **配置** → **TMDB 配置**：

- **API Key**: 从 [TMDB](https://www.themoviedb.org/settings/api) 获取
- **语言**: 默认 `zh-CN`
- **代理**: 如需要，配置 HTTP 代理

## 日志管理

日志文件：`activity.log`（位于项目根目录）

**日志级别**（在 WebUI 配置）：
- `DEBUG`: 详细调试信息（开发时使用）
- `INFO`: 正常运行信息（默认）
- `WARNING`: 警告信息
- `ERROR`: 错误信息

**日志轮转**：
- 单文件最大：10MB（可配置）
- 保留数量：5 个备份（可配置）

## 数据库维护

### 重建数据库

如数据库损坏或需要重置：

1. 停止服务
2. 删除 `bridge.db`
3. 启动服务（自动重建）

**注意**：重建数据库会丢失所有同步历史记录，请谨慎操作。

## 故障排查

### 问题 1: WebUI 无法访问

**症状**: 浏览器无法打开 `http://127.0.0.1:8579`

**排查步骤**:
1. 检查服务是否启动：查看控制台输出
2. 检查端口占用：`netstat -ano | findstr :8579`
3. 检查防火墙：确保 8579 端口未被阻止

### 问题 2: OpenList 连接失败

**症状**: WebUI 显示 "OpenList 离线" 或测试连接失败

**排查步骤**:
1. 确认 OpenList 服务可访问：`ping your-openlist`
2. 确认 WebDAV 地址正确：`http://your-openlist:5244`
3. 确认用户名/密码正确
4. 如启用 2FA，确认 TOTP 密钥正确
5. 查看日志：`activity.log` 中的详细错误信息

### 问题 3: 文件未同步到 B 区

**症状**: A 区有新文件，但 B 区未出现

**排查步骤**:
1. 检查 A 区监控路径配置是否正确
2. 检查 B 区根目录是否存在且可写
3. 查看日志：搜索 `[SyncService]` 相关日志
4. 检查血统校验：文件可能因血统不符被拒绝
5. 检查重复检测：文件可能因重复被隔离

### 问题 4: 数据库只读错误

**症状**: 日志中出现 `readonly connection` 错误

**排查步骤**:
1. 检查数据库文件权限：确保当前用户有写权限
2. 检查磁盘空间：确保磁盘未满
3. 检查文件锁定：确保没有其他进程锁定数据库
4. 重启服务：程序会自动尝试修复

## 性能调优

### 数据库优化

程序已内置以下优化（无需手动配置）：
- WAL 模式（并发读写）
- 64MB 页缓存
- 256MB mmap 映射
- NORMAL 同步模式

### 大批量同步

如有大量文件（>10,000）需同步：

1. 首次同步前，确保数据库为空（删除 `bridge.db`）
2. 启动服务，等待初始扫描完成
3. 观察日志，确认同步进度

---

## 安全建议

1. **网络隔离**: WebUI 仅监听局域网，不要暴露到公网
2. **备份配置**: 定期备份 `config.toml` 和数据库文件
3. **日志审计**: 定期检查日志，关注 WARNING/ERROR 级别日志
4. **权限控制**: 运行服务的用户应有足够权限访问 A/B/C 区
5. **测试连接**: 修改配置后，使用 "测试连接" 功能验证
