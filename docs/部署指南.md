# 部署指南

本文档介绍如何在 Windows 环境下部署和运行 openlist_strm_bridge。

---

## 系统要求

- **操作系统**: Windows 10/11 或 Windows Server 2016+
- **Python**: 3.11+（推荐使用嵌入式启动脚本，也可使用系统 Python）
- **磁盘空间**: 至少 500MB（含数据库和日志）
- **网络**: 可访问 OpenList 服务（局域网或公网）

---

## 快速开始

### 1. 下载项目

```
# 直接下载 ZIP
# 从 GitHub Releases 下载最新版本
```

### 2. 安装依赖

项目可使用嵌入式 Python 环境，无需手动安装依赖。

如需使用系统 Python：

```powershell
python -m pip install -r requirements.txt
```

**依赖列表**（requirements.txt）：
- `watchdog>=4.0.0` - 文件系统监控
- `requests>=2.31.0` - HTTP 客户端
- `lxml>=5.0.0` - XML 解析（WebDAV）
- `tomli>=2.0.1` - TOML 配置解析（Python < 3.11）

**开发/测试依赖**（src/tests/requirements-dev.txt）：
- `pytest>=7.0.0` - 测试框架
- `pytest-cov>=4.0.0` - 覆盖率报告（可选）
- `flask>=2.0.0` - Mock TMDB 服务器（仅测试用）

```bash
pip install -r src/tests/requirements-dev.txt
```

**Simple 分词器（中文搜索硬依赖）**：

中文搜索基于 SQLite FTS5 + `simple` 分词器（cppjieba 封装，[wangfenjin/simple](https://github.com/wangfenjin/simple) 项目，内置版本 v0.7.1）。相关资源统一放置在 `src/tokenizers/simple/` 目录下：

- `simple.dll` - 分词器扩展（Windows x64 构建）
- `VERSION` - 版本说明
- `README.md` - 接入与版本说明
- `assets/dict/` - cppjieba 词典资源

`database.py` 的 `_load_simple_tokenizer` 与 `tmdb_watchlist_db.py` 的 `_load_simple_into` 会在数据库连接时自动加载该扩展。**该扩展是中文搜索的硬性依赖**：若 `simple.dll` 缺失或被移除，程序会软降级为 `unicode61` 分词器，此时中文（及中日韩等）搜索将无法正确分词，导致中文搜索失效（仅英文/数字可正常匹配）。请勿删除或移动 `src/tokenizers/simple/` 目录。详细接入与版本信息见该目录下的 `README.md`。

### 3. 配置文件

复制示例配置：

```powershell
Copy-Item config.toml.example config.toml
```

编辑 `config.toml`：

```toml
[local]
# SQLite 数据库文件路径（相对路径基于 config.toml 所在目录）
db_file = "./bridge.db"

[webui]
# WebUI 管理面板配置
enabled = true
port = 8579
bind = "0.0.0.0"  # 0.0.0.0 = 局域网可访问，127.0.0.1 = 仅本机
```

**重要**：OpenList 连接配置、路径配置等已迁移至 WebUI 管理面板，首次启动后通过 WebUI 配置。

### 4. 启动服务

```powershell
# 方式一：使用批处理脚本（推荐）
.\嵌入式启动.bat

# 方式二：直接运行
python src/webui/server.py
```

启动后访问 `http://127.0.0.1:8579` 即可使用 WebUI 管理面板。

### 5. 访问 WebUI

启动后访问：`http://127.0.0.1:8579`

> **管理密码**：首次启动时系统自动生成随机密码，**仅打印到控制台一次**（stdout），不写入日志文件，后续重启不再显示。忘记密码可运行 `python reset_admin.py` 重置。

首次启动需配置：
1. **OpenList 配置** → 填写 WebDAV 地址、用户名、密码、TOTP 密钥（如有）
2. **OpenList 配置** → 填写 A↔B 目录映射（每个 A 根对应一个 B 根）+ C 区根目录
3. **TMDB 配置**（可选）→ 填写 API Key 以启用待看列表功能

### 6. 新手引导 / Onboarding

首次启动（且尚未完成引导）时，WebUI 会自动弹出 **新手引导**，以分步形式带领完成核心配置，共 **7 个步骤**：

1. **password** - 确认/记录管理密码
2. **tmdb** - 配置 TMDB API Key（可选但推荐）
3. **openlist** - 配置 OpenList WebDAV 连接
4. **main** - 启动主程序
5. **view_ab** - 了解 A 区 / B 区（引擎输出区 / 媒体库消费区）
6. **tmdb_refresh** - 触发 TMDB 待看列表刷新
7. **tmdb_match** - 检测 TMDB 收录状态

**完成与跳过路径**：
- 逐步完成：每完成一步，前端通过 `POST /api/onboarding/complete-step` 标记该步完成；
- 整体完成或跳过：通过 `POST /api/webui/config/ui`，提交 `{ "onboarding_completed": "1" }` 一次性完成或跳过剩余步骤。

**状态存储**：引导状态（是否完成/跳过、各步骤完成情况）保存在 `tmdb_watchlist.db` 的 `webui_config` 表中（键名形如 `onboarding_completed`、`onboarding_{step}_completed`）。已完成的引导不会在后续重启时再次弹出；如需重新查看，可手动清空对应配置键。

## 首次配置流程

### Step 1: 配置 OpenList 连接

访问 WebUI → **配置** → **OpenList 配置**：

- **WebDAV 地址**: `http://your-openlist:5244`
- **用户名**: OpenList 管理员用户名
- **密码**: OpenList 管理员密码
- **TOTP 密钥**: 如启用 2FA，填写密钥（可选）

点击 **测试连接** 验证配置。

### Step 2: 配置路径

访问 WebUI → **配置** → **OpenList 配置**：

- **A↔B 目录映射**（`a_b_mappings`）：每个 A 区根目录对应一个 B 区根目录，逐行填写。程序通过 STRM 引擎自动发现 A 区根列表，你只需为每个 A 根填写 B 根（如 `D:\MediaLibrary`）
- **C 区根目录**: 幽灵收容区路径（如 `D:\GhostFiles`），为全局单值
- **STRM 引擎路径**: OpenList STRM 引擎挂载路径（如 `/strm`）
- **主动刷新路径**（`refresh_paths`）：填写需要定期刷新的 STRM 入口路径；若留空，程序跳过周期性扫描但 B 区删除联动照常

### Step 3: 配置行为（可选）

访问 WebUI → **配置** → **行为配置**：

- **启动时同步**: 是否在启动时执行全量同步
- **幽灵保护时间**: 文件删除后保留恢复窗口的时间（秒）
- **动作模式**: `MOVE`（移动到回收站）或 `DELETE`（直接删除，危险）
- **全量审计周期**（`full_audit_interval_days`）：每隔多少天执行一次 A→B 全量审计。默认为周期执行，设为 `0` 可关闭。
  - 周期配置来源：`tmdb_watchlist.db` 的 `webui_config` 表，scope=`openlist`，DB 键为 `refresh_full_audit_interval_days`
  - 上次审计时间来源：`bridge.db` 的 `sync_control` 表，键为 `last_full_audit_at`
  - 两者是不同的持久化字段，不要混为一谈

### Step 4: 配置 TMDB（可选）

访问 WebUI → **配置** → **TMDB 配置**：

- **API Key**: 从 [TMDB](https://www.themoviedb.org/settings/api) 获取
- **语言**: 默认 `zh-CN`
- **代理**: 如需要，配置 HTTP 代理

### Step 5: 区域搜索与番剧 / 电影分类

配置完成后，可在 **区域详情（Area）** 页面使用区域搜索功能：

- **区域搜索**：在区域页面使用搜索框输入关键词，实际调用 `GET /api/area/{area}?q=<关键词>`，后端通过 FTS5 全文索引检索（含中文需依赖 Simple 分词器，见上文依赖说明）。搜索词中的特殊字符（如 `[`、`]` 等）会经 `_escape_fts5_query` 统一转义，避免 FTS5 语法报错。
- **番剧 / 电影分类 Tab**：通过 `kind` 参数在 `anime`（番剧）/ `movie`（电影）/ `other`（其他）/ `all`（全部）之间切换，对应区域页面的分类标签页。分类统计与筛选均基于媒体 `kind` 字段。
- **详情搜索**：点击某部媒体进入详情时，调用 `GET /api/area/{area}/detail?media=<媒体名>`，该接口走 `LIKE` 模糊匹配返回该媒体的所有记录。

> 提示：若中文搜索无结果，请优先检查 `src/tokenizers/simple/simple.dll` 是否存在（Simple 分词器缺失会导致中文搜索降级失效）。

## 运行模式

### 前台运行

```powershell
python src/webui/server.py
```

按 `Ctrl+C` 停止服务。

### 后台运行

Windows 环境下可通过 VBS 脚本隐藏控制台窗口，实现「后台运行」效果。项目自带 `后台带Bridge启动webui.vbs`，该脚本会设置 `BRIDGE_HEADLESS=1` 环境变量并以隐藏窗口（参数 `0`）启动 `python src\webui\server.py`。

**无头模式（`BRIDGE_HEADLESS=1`）**：`server.py` 的 `main()` 检测到该环境变量后，自动跳过交互菜单，直接启动主程序（等效于选择「1. 自动启动主程序」），然后进入静默等待循环（不读取 stdin），除非手动停止主程序，否则始终运行。

**使用方法**：

```powershell
# 双击运行自带 VBS 脚本（推荐）
双击 后台带Bridge启动webui.vbs
```

VBS 脚本内容如下：

```vbscript
Set WshShell = CreateObject("WScript.Shell")
WshShell.CurrentDirectory = CreateObject("Scripting.FileSystemObject").GetParentFolderName(WScript.ScriptFullName)
WshShell.Environment("PROCESS")("BRIDGE_HEADLESS") = "1"
WshShell.Run "python src\webui\server.py", 0, False
Set WshShell = Nothing
```

**关键限制**：

1. **不支持进程级管理**。VBS 方案不提供单实例检查、PID 锁、服务注册、优雅停止等能力。停止服务需手动结束 `python.exe` 进程（任务管理器或 `taskkill`）。
2. **仍不支持 PID 锁/优雅停止**。无头模式下程序进入 `while True` 静默等待，无法通过标准信号优雅退出，必须通过任务管理器或 `taskkill` 强制结束。

## 日志管理

日志文件：`strm_bridge.log`（位于项目根目录）

**日志级别**（在 WebUI 配置）：
- `DEBUG`: 详细调试信息（开发时使用）
- `INFO`: 正常运行信息（默认）
- `WARNING`: 警告信息
- `ERROR`: 错误信息

**日志轮转**：
- 单文件最大：2MB（可配置）
- 保留数量：5 个备份（可配置）

## 数据库维护

### 重建数据库

如数据库损坏或需要重置：

1. 停止服务
2. 删除 `bridge.db`
3. 启动服务（自动重建）

**注意**：重建数据库会丢失所有同步历史记录，请谨慎操作。

## 故障排查

### 问题 1: WebUI 无法访问

**症状**: 浏览器无法打开 `http://127.0.0.1:8579`

**排查步骤**:
1. 检查服务是否启动：查看控制台输出
2. 检查端口占用：`netstat -ano | findstr :8579`
3. 检查防火墙：确保 8579 端口未被阻止

### 问题 2: OpenList 连接失败

**症状**: WebUI 显示 "OpenList 离线" 或测试连接失败

**排查步骤**:
1. 确认 OpenList 服务可访问：`ping your-openlist`
2. 确认 WebDAV 地址正确：`http://your-openlist:5244`
3. 确认用户名/密码正确
4. 如启用 2FA，确认 TOTP 密钥正确
5. 查看日志：`strm_bridge.log` 中的详细错误信息

### 问题 3: 文件未同步到 B 区

**症状**: A 区有新文件，但 B 区未出现

**排查步骤**:
1. 检查 A 区监控路径配置是否正确
2. 检查每个映射的 B 区根目录是否存在且可写
3. 查看日志：搜索 `同步`、`SyncService` 相关日志
4. 检查血统校验：文件可能因血统不符被拒绝
5. 检查重复检测：文件可能因重复被隔离

### 问题 4: 数据库只读错误

**症状**: 日志中出现 `readonly connection` 错误

**排查步骤**:
1. 检查数据库文件权限：确保当前用户有写权限
2. 检查磁盘空间：确保磁盘未满
3. 检查文件锁定：确保没有其他进程锁定数据库
4. 重启服务：程序会自动尝试修复

## 性能调优

### 数据库优化

程序已内置以下优化（无需手动配置）：
- WAL 模式（并发读写）
- 64MB 页缓存
- 256MB mmap 映射
- NORMAL 同步模式

### 大批量同步

如有大量文件（>10,000）需同步：

1. 首次同步前，确保数据库为空（删除 `bridge.db`）
2. 启动服务，等待初始扫描完成
3. 观察日志，确认同步进度

---

## 安全建议

1. **网络隔离**: WebUI 仅监听局域网，不要暴露到公网
2. **备份配置**: 定期备份 `config.toml` 和数据库文件
3. **日志审计**: 定期检查日志，关注 WARNING/ERROR 级别日志
4. **权限控制**: 运行服务的用户应有足够权限访问 A/B/C 区
5. **测试连接**: 修改配置后，使用 "测试连接" 功能验证
