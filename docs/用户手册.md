## 产品概述

openlist_strm_bridge 是 OpenList STRM 引擎的智能同步中间件，核心职责：

- **自动同步**: 将 A 区（OpenList STRM 引擎输出）的文件同步到 B 区（媒体库消费区）
- **智能重命名**: 自动识别媒体类型，标准化文件命名
- **字幕同步**: 自动同步字幕文件，电影同目录，番剧按季归档
- **血统校验**: 防止文件越界、脱群等非法操作
- **云端联动**: 删除操作同步到云端，支持回收站重建
- **待看列表**: 集成 TMDB 待看列表，对比本地收录状态

## 快速入门

### 1. 启动服务

```powershell
.\嵌入式启动.bat
```

启动后浏览器打开 `http://127.0.0.1:8579` 即可使用 WebUI 管理面板。

或直接运行：

```powershell
python src/webui/server.py
```

### 2. 访问 WebUI

浏览器打开：`http://127.0.0.1:8579`

> **首次启动时**，系统会自动生成随机管理密码并打印到控制台（仅一次，不写入日志文件）。后续重启不会再次显示。忘记密码可运行 `python reset_admin.py` 重置。

### 3. 新手引导 / Onboarding

首次启动（且尚未完成引导）时，WebUI 会自动弹出 **新手引导**，以分步形式带你完成核心配置，共 **7 个步骤**：

1. **password** - 确认并记录管理密码（仅在控制台打印一次）
2. **tmdb** - 配置 TMDB API Key（可选但推荐，用于待看列表）
3. **openlist** - 配置 OpenList WebDAV 连接
4. **main** - 启动主程序
5. **view_ab** - 了解 A 区（引擎输出区）与 B 区（媒体库消费区）
6. **tmdb_refresh** - 触发 TMDB 待看列表刷新
7. **tmdb_match** - 检测 TMDB 收录状态

**完成与跳过**：
- 可逐步跟随引导完成，每完成一步自动标记；
- 也可在任意步骤直接 **跳过 / 完成**，整体完成或跳过通过 WebUI 配置一次性生效。

引导状态保存在 `tmdb_watchlist.db` 的 `webui_config` 表中，已完成引导后重启不会再弹出。

### 4. 配置 OpenList

首次启动需配置 OpenList 连接：

1. 点击左侧菜单 **配置** → **OpenList 配置**
2. 填写：
   - **WebDAV 地址**: `http://your-openlist:5244`
   - **用户名**: OpenList 管理员用户名
   - **密码**: OpenList 管理员密码
   - **TOTP 密钥**: 如启用 2FA（可选）
3. 点击 **测试连接** 验证
4. 点击 **保存**

### 5. 配置路径

1. 点击 **配置** → **OpenList 配置**
2. 填写 A↔B 映射（每个 A 区根目录对应一个 B 区根目录）：
   - 在 **A↔B 目录映射** 区域，逐行为每个 A 区根目录填写对应的 **B 区根目录**（如 `D:\MediaLibrary`）
   - 程序通过 STRM 引擎自动发现 A 区根目录列表，你只需为每个 A 根填写 B 根
   - **C 区根目录**: 幽灵收容路径（如 `D:\GhostFiles`），为全局单值
3. 可选：在 **主动刷新路径** 中填写需要定期刷新的 STRM 入口路径。若留空，程序将跳过周期性扫描，但 B 区删除联动仍正常工作
4. 点击 **保存**

### 6. 开始使用

配置完成后，程序会自动监控 A 区变化并同步到 B 区。

## WebUI 管理面板

WebUI 是 openlist_strm_bridge 的管理界面，提供以下功能：

### 仪表盘（Dashboard）

显示系统整体状态：
- **A 区文件数**: 引擎输出区文件总数
- **B 区文件数**: 媒体库消费区文件总数
- **C 区文件数**: 幽灵收容区文件总数
- **TMDB 状态**: 是否已配置 TMDB API
- **数据库大小**: SQLite 数据库占用空间
- **运行时间**: 服务启动时长

### 区域详情（Area）

查看 A/B/C 区详细信息：

#### A 区（引擎输出区）

- 文件列表
- 云路径映射
- 同步状态
- 最近变更

#### B 区（媒体库消费区）

- 文件列表
- 状态统计（有效/重复/隔离）
- 重复文件隔离情况
- 字幕同步情况

#### C 区（幽灵收容区）

- 失效文件列表
- 挂载点变更记录
- 隔离文件诊断区（不提供自动恢复；隔离文件需手动重命名去掉 `.duplicate` 后缀后重启同步引擎以重新纳入；也可使用更安全的安全工具 `python src/tools/repair_false_duplicates.py --db bridge.db` 先 dry-run 扫描「假 duplicate」，确认后加 `--apply` 写库恢复）

### 记录查询（Records）

查询同步历史记录：
- 按区域筛选（A/B/C）
- 按文件名搜索
- 分页浏览

### 配置管理（Config）

管理所有配置项：

#### OpenList 配置

- WebDAV 连接信息
- 路径配置
- 刷新策略
- 行为配置

#### TMDB 配置

- API Key / Access Token
- 语言设置
- 代理配置
- 缓存策略

#### WebUI 配置

- 端口设置
- 绑定地址
- 主题设置

### 日志查看（Logs）

点击工具栏的"刷新当前日志"按钮可手动获取最新日志。

## 核心功能

### 1. 自动同步

**工作原理**：
1. 监控 A 区文件变化（创建/修改/删除）
2. 提取云端真实路径
3. 计算文件指纹（内容哈希）
4. 血统校验（验证文件来源合法性）
5. 命名打分（评估文件名质量）
6. 复制到 B 区并入库

**触发条件**：
- 启动时全量同步（可配置）
- 文件变化实时同步
- 定时刷新（可配置间隔）

### 2. 智能重命名

**命名规则**：
- 电影：`电影名 (年份).strm`
- 番剧：`番剧名/Season XX/S01E01 - 集名.strm`

**打分机制**：
系统使用四元组 `(is_standard, match_count, path_len, name)` 进行元组比较（非加法积分）：
- 标准刮削命名（S01E01）排在非标准命名之前
- 与 WebDAV 路径的目录层级匹配越多，优先级越高
- 路径越短，优先级越高
- 文件名字母序作为最终排序

**劣质命名处理**：
- 自动重命名为 `.duplicate` 后缀
- 物理隔离，不影响媒体库

### 3. 字幕同步

**电影字幕**：
- 保持与 STRM 文件同目录
- 命名：`电影名.语言.ass`

**番剧字幕**：
- 按季归档到 `Season XX/` 目录
- 命名：`S01E01.forced.zho.简体.ass`
- 支持 `.ass`、`.srt`、`.ssa` 格式

**语言识别**：
- 自动识别字幕语言（中文/英文/日文等）
- 支持 forced 标记（强制字幕）

### 4. 血统校验

**校验规则**：
- 文件必须来自合法的 STRM 引擎路径
- 禁止跨库移动（如从番剧库移到电影库）
- 单集脱群改名触发 30 秒观察期
- 观察期内无后续操作，判定为非法越界，物理删除

**安全机制**：
- 血统校验失败的文件会被隔离
- 记录详细日志供审计
- 隔离文件需手动重命名去掉 `.duplicate` 后缀并重启同步引擎以重新纳入（无自动恢复按钮）

### 5. 云端联动

**删除操作**：
1. 用户在 B 区删除 STRM 文件
2. 程序截取云端真实目录结构
3. 在配置的回收站内重建原文件夹树
4. 调用 API 移动文件到回收站
5. 触发 OpenList 索引更新

**恢复操作**（未实现）：
- 当前版本**未实现**"从云端回收站恢复文件到原路径"的功能。
- B 区文件被删除后，唯一恢复途径是 A 区源复制（`restore_b_file_from_a`），
  并非从云端回收站恢复；数据库记录与 B 区重新扫描不会自动关联该恢复动作。

### 6. TMDB 待看列表

**功能**：
- 同步 TMDB 待看列表到本地
- 对比本地收录状态
- 显示已收录/待看/有疑问状态

**状态说明**：
- **已收录**: 本地已有对应 STRM 文件
- **未收录**: 本地无对应文件
- **有疑问**: 文件名匹配度低，需人工确认

**手动覆盖**：
- 支持手动标记收录状态
- 覆盖后会记录操作日志

### 7. 中文搜索（FTS5 + Simple 分词器）

媒体库搜索基于 **SQLite FTS5 全文索引**，并依赖 **Simple 分词器** 实现中文（及中日韩等）正确分词。

**Simple 分词器是硬依赖**：它位于 `src/tokenizers/simple/`（封装自 cppjieba，[wangfenjin/simple](https://github.com/wangfenjin/simple) 项目，内置 v0.7.1，含 `simple.dll` 与词典资源）。`database.py` 与 `tmdb_watchlist_db.py` 在连接数据库时自动加载该扩展。若 `simple.dll` 缺失，程序会软降级为 `unicode61` 分词器，此时中文搜索将无法正确分词而失效（仅英文/数字可匹配）。请勿删除该目录。

**搜索方式**：

- **区域搜索（FTS5）**：在区域详情页使用搜索框，实际调用 `GET /api/area/{area}?q=<关键词>`。查询词会经 `_escape_fts5_query` 转义，因此对含特殊字符的标题也能正常检索，例如搜索 `进击的巨人[限制级]` 时方括号会被安全转义，不会触发 FTS5 语法错误。
- **番剧 / 电影分类 Tab**：通过 `kind` 参数在 `anime`（番剧）/ `movie`（电影）/ `other`（其他）/ `all`（全部）之间切换，对应页面顶部的分类标签页，用于按媒体类型筛选。
- **详情模糊搜索（LIKE）**：点击某部媒体进入详情时，调用 `GET /api/area/{area}/detail?media=<媒体名>`，该接口走 `LIKE` 模糊匹配返回该媒体的全部记录，适合精确定位单部作品。

**排错提示**：中文搜索无结果时，请优先确认 `src/tokenizers/simple/simple.dll` 存在且未被移动；并确认已配置 OpenList / TMDB 数据源使媒体已入库。

## 常见问题

### Q1: 为什么文件没有同步到 B 区？

**可能原因**：
1. A 区监控路径配置错误
2. 文件血统校验失败
3. 文件被判定为重复
4. B 区目录不可写

**排查步骤**：
1. 查看日志：搜索 `同步`、`SyncService` 相关日志
2. 检查 A 区路径：确认路径在 OpenList STRM 引擎监控范围内
3. 检查 B 区权限：确认当前用户有写权限
4. 检查重复检测：查看是否有 `.duplicate` 文件

### Q2: 如何手动触发全量审计？

**方法**：
1. 访问 WebUI → **仪表盘**
2. 点击 **立即全量审计** 按钮
3. 等待审计完成

**注意**：全量审计耗时较长（取决于文件数量），建议在空闲时执行。

### Q3: 数据库损坏了怎么办？

**重建步骤**：
1. 停止服务
2. 删除 `bridge.db`
3. 启动服务（自动重建）

**注意**：重建会丢失同步历史，请谨慎操作。建议定期备份数据库。

### Q4: 如何查看同步进度？

**查看方法**：
1. 访问 WebUI → **日志**
2. 在日志类型切换中选择"主程序日志"或"TMDB 操作日志"
3. 点击"刷新当前日志"按钮获取最新日志

**日志示例**（示意性，实际格式含时间戳）：
```
[14:30:01] [INFO] 开始同步 A 区文件...
[14:30:05] [INFO] 已同步 100/1000 个文件
[14:35:12] [INFO] 同步完成，共处理 1000 个文件
```

### Q5: 如何配置 TMDB 代理？

**配置步骤**：
1. 访问 WebUI → **配置** → **TMDB 配置**
2. 填写：
   - **代理地址**: `http://proxy:port`
   - **启用代理**: 是
3. 点击 **保存**

**注意**：代理地址必须是 HTTP 代理，不支持 SOCKS。

### Q6: 如何导出待看列表？

**导出步骤**：
1. 访问 WebUI → **TMDB 待看列表**
2. 点击 **导出 CSV** 按钮
3. 选择保存路径
4. 确认导出

**CSV 格式**：
```csv
状态,TMDB ID,类型,标题,原标题,发布日期,评分
已收录,12345,movie,电影名,Movie Name,2024-01-01,8.5
待看,67890,tv,剧集名,Series Name,2024-02-01,9.0
```

### Q7: 如何查看文件云路径？

**查看方法**：
1. 访问 WebUI → **区域详情** → **A 区** 或 **B 区**
2. 点击文件名
3. 查看 **云路径** 字段

**云路径格式**：
```
/strm/番剧/进击的巨人/Season 01/S01E01.strm
```

### Q8: 如何禁用自动同步？

**禁用步骤**：
1. 访问 WebUI → **配置** → **行为配置**
2. 取消勾选 **启动时同步**
3. 点击 **保存**

**注意**：禁用后需手动触发同步。

### Q9: 如何查看重复文件？

**查看方法**：
1. 访问 WebUI → **区域详情** → **B 区**
2. 重复文件会以 `.duplicate` 后缀自动隔离，不会出现在正常媒体库扫描中
3. 在 B 区文件列表中查看带 `.duplicate` 后缀的文件

**处理建议**：
- 系统自动保留标准命名文件（S01E01 格式），劣质命名文件被标记为 `.duplicate`
- 如需恢复被隔离的文件，需手动重命名去掉 `.duplicate` 后缀并重启同步引擎以重新纳入
