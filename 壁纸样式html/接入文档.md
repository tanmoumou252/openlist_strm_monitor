# Ink Reveal 壁纸晕染效果接入文档

## 1. 效果说明

这是一个三层结构的壁纸揭示效果：

- 底层：壁纸背景图
- 中层：一层纯色白色遮罩
- 上层：鼠标移动时被擦除的水墨晕染 canvas

核心实现是用 Canvas 的 `destination-out` 让鼠标轨迹把白色遮罩局部“挖掉”，从而露出底部壁纸。

---

## 2. 当前精简文件结构

本项目现在只保留 5 个文件：

- `ink-reveal-demo.html`：最小可运行 demo
- `ink-reveal.css`：样式
- `ink-reveal.js`：交互逻辑
- `wallpaper.png`：唯一壁纸资源
- `接入文档.md`：接入说明

没有额外字体、没有重复的 `dist/src/examples` 目录、没有原始保存网页残留文件。

## 4. CSS 接入

引入 `ink-reveal.css`：

```html
<link rel="stylesheet" href="./ink-reveal.css">
```

或者复制其中的样式到你的主 CSS 文件中。

### 样式关键点

必须满足：

```css
.ink-reveal {
  position: relative;
  overflow: hidden;
  isolation: isolate;
}

.ink-reveal__bg,
.ink-reveal__mask {
  position: absolute;
  inset: 0;
}

.ink-reveal__mask {
  pointer-events: none;
  z-index: 1;
}

.ink-reveal__content {
  position: relative;
  z-index: 2;
}
```

### 背景图设置方式

推荐直接给 `.ink-reveal__bg` 设置背景图：

```html
<div class="ink-reveal__bg" style="background-image: url('./wallpaper.jpg');"></div>
```

或在 CSS 里写：

```css
.ink-reveal__bg {
  background-image: url('./wallpaper.jpg');
  background-position: center bottom;
  background-repeat: no-repeat;
  background-size: cover;
}
```

## 5. JS 接入

引入 `ink-reveal.js`：

```html
<script src="./ink-reveal.js"></script>
```

然后初始化：

```html
<script>
  window.initInkReveal({
    root: "#inkReveal",
    maskSelector: ".ink-reveal__mask",
    bgSelector: ".ink-reveal__bg",
    maskColor: "252, 250, 248",
    lifetime: 1800,
    stampStep: 10,
    rStart: 8,
    rEnd: 128,
    rVary: 0.30,
    brushSize: 320,
    brushVariants: 5,
    maxStamps: 160,
    maxDpr: 2
  });
</script>
```

## 6. 技术实现细节

### 6.1 遮罩层

canvas 初始会被整块填充为白色：

```js
ctx.fillStyle = "rgb(252, 250, 248)";
ctx.fillRect(0, 0, w, h);
```

这就是白色遮罩。

### 6.2 擦除方式

每一帧：

1. 重新把 canvas 填满白色
2. 遍历所有未过期墨点
3. 用 `destination-out` 将墨点区域擦掉

```js
ctx.globalCompositeOperation = "destination-out";
ctx.drawImage(...);
```

### 6.3 墨刷生成

为了让边缘更柔和，不直接画圆，而是先在离屏 canvas 里预渲染一个“墨刷”：

- 320×320 的离屏 canvas
- 径向渐变做软边
- 96 段轻微抖动做自然边界
- 生成 5 个变体，避免每个墨点都一样

### 6.4 墨点生命周期

每个 stamp 都有：

- `born`：生成时间
- `rmax`：最大扩张半径
- `brush`：使用哪个墨刷变体

它会随时间：

- 扩张
- 淡出
- 过期后移除

## 7. 推荐使用场景

适合：

- 首页 hero 背景
- 品牌视觉页
- 展示页/作品集页
- 有壁纸感的大图横幅

不太适合：

- 超小卡片
- 高密度列表项
- 强交互的实时图表区域

## 8. 响应式和设备兼容建议

### 桌面端

完整启用效果。

### 触屏设备

建议隐藏 canvas：

```css
@media (hover: none), (pointer: coarse) {
  .ink-reveal__mask {
    display: none;
  }
}
```

因为触屏没有 hover，直接显示壁纸更自然。

## 9. 常用参数说明

### `lifetime`
墨点从出现到消失的总时间。

- 更大：更慢、更柔
- 更小：更快、更干脆

### `stampStep`
鼠标轨迹上 stamp 的间隔。

- 更小：更连贯
- 更大：更稀疏

### `rStart`
起始半径。

- 更小：刚出现更细
- 更大：起笔更重

### `rEnd`
最大半径。

- 更大：晕染更广
- 更小：更克制

### `rVary`
每个 stamp 的随机幅度。

- 更大：更有随机感
- 更小：更稳定

---

## 10. 默认推荐值

如果你不想调参，直接用这组：

```js
{
  lifetime: 1800,
  stampStep: 10,
  rStart: 8,
  rEnd: 128,
  rVary: 0.30,
  brushSize: 320,
  brushVariants: 5,
  maxStamps: 160,
  maxDpr: 2
}
```

这组参数的特点是：

- 边缘柔和
- 速度不至于太慢
- 鼠标移动时能跟上
- 有墨晕感，但不会像画笔拖尾

## 12. 接入时最常见的问题

### 问题 1：看不到效果

检查：

- 容器是否有高度
- `canvas` id 是否匹配
- 浏览器是否支持 hover
- `bg` 是否真的有图片

### 问题 2：遮罩不对齐

检查：

- 容器是否 `position: relative`
- `canvas` 是否 `position: absolute; inset: 0`
- 是否有 `resize()`

### 问题 3：看起来像拖尾画笔

调小：

- `lifetime`
- `stampStep`

### 问题 4：太快消失

调大：

- `lifetime`
- `rEnd`
